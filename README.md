# Natural Language Processing

This repository contains practical implementations of fundamental Natural Language Processing (NLP) techniques using Python, NLTK, and spaCy.

## Practicals

1. Tokenization
2. Stemming and Lemmatization
3. Stopword Removal
4. Part-of-Speech Tagging
5. Parsing and Chunking
6. Named Entity Recognition

## Technologies Used

* Python
* NLTK
* spaCy
* Jupyter Notebook

## Installation

Install the required Python libraries:

```bash
pip install nltk spacy jupyter
```

For the Named Entity Recognition practical, install the spaCy English language model:

```bash
python -m spacy download en_core_web_sm
```

Required NLTK resources are downloaded within the notebooks when necessary.

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/NLP.git
```

2. Navigate to the repository:

```bash
cd NLP
```

3. Install the required dependencies.

4. Start Jupyter Notebook:

```bash
jupyter notebook
```

5. Open the required `.ipynb` file and run the cells sequentially.
